## 1. why - 목적

* 일일 할 일을 주간 계획과 1년 목표에 연결해 관리
* 단기 실행이 장기 목표에 어떻게 기여하는지 확인
* 완료 현황을 기반으로 주간 진행률 자동 추적

## 2. Who - 타깃 사용자

* 일일 할 일과 장기 목표를 함께 관리하고 싶은 사용자
* 목표 달성 과정을 구조적으로 확인하고 싶은 사용자

## 3. User Flow

* 1년 목표 생성
* 주간 계획 생성 및 1년 목표 연결
* 할 일 생성 및 주간 계획 연결
* 할 일을 `todo / doing / done`으로 관리
* 드래그 앤 드롭으로 상태 변경
* 완료된 할 일을 기준으로 주간 진행률 자동 반영

## 4. 기능 요구 사항

### P0 - 핵심 기능

* 할 일 CRUD

  * 생성 / 조회 / 수정 / 삭제
* 할 일 상태 관리

  * `todo / doing / done`
* 드래그 앤 드롭 상태 변경
* 기간별 관리

  * 일일 할 일
  * 주간 계획
  * 1년 목표
* 목표 구조 연결

  * 할 일 → 주간 계획 → 1년 목표
* 주간 진행률 자동 계산

  * 완료된 할 일 / 전체 할 일

### P1 - 추가기능

* 일일 / 주간 / 1년 목표 화면 제공
* 주간 진행률 시각화
* 상태 및 기간별 필터
* 완료된 할 일 시각적 구분
